# Gading Paribu — Personal Portfolio

Website portofolio statis menggunakan HTML, CSS, dan JavaScript murni.

## Cara menjalankan
1. Ekstrak folder ZIP.
2. Buka folder `gading_paribu_portfolio`.
3. Klik dua kali `index.html`, atau buka folder menggunakan Visual Studio Code.
4. Disarankan memakai ekstensi Live Server di VS Code agar perubahan mudah dilihat.

## Bagian yang wajib diganti sebelum dipublikasikan
- Ganti placeholder foto dengan foto milik sendiri.
- Ganti `emailkamu@example.com` dengan email aktif.
- Ganti tautan LinkedIn dan GitHub (`href="#"`) dengan profil yang benar.
- Letakkan file CV PDF di `assets/CV-Gading-Paribu.pdf`.
- Tambahkan tautan repository/demo pada setiap proyek.
- Lengkapi riwayat pendidikan sebelumnya jika ingin ditampilkan.

## Mengganti placeholder foto
Cari elemen dengan class `image-placeholder` di `index.html`, lalu ganti dengan:
`<img src="assets/images/nama-foto.jpg" alt="Deskripsi foto">`
Tambahkan CSS `width:100%;height:100%;object-fit:cover;` pada gambar agar memenuhi area.

Semua foto masih berupa placeholder, bukan foto pribadi atau dokumentasi asli.
